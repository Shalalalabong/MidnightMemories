# 🖤 Pixelated Kuromi Decorations Directory

Drop your custom pixelated Kuromi images into this folder (`public/decorations/kuromi/`) when publishing the website!

### Recommended File Names:
- `kuromi1.png`
- `kuromi2.png`
- `kuromi3.png`
- `kuromi_skull.png`
- `kuromi_sticker.png`

Transparent PNGs or animated GIFs with pixel art aesthetics look best. 
To add or customize your image filenames, open `src/data/kuromiDecor.ts`.

Even without custom images added, built-in crisp pixelated Kuromi sprites automatically animate and drift in the background!
